Diagnose Java application issues including OutOfMemoryError, high CPU usage, thread problems, and memory leaks. This tool analyzes running Java processes to provide detailed diagnostic information including memory usage, CPU consumption, thread states, garbage collection patterns, system resource usage, and potential issues. It can identify stuck threads, deadlocks, memory leaks, frequent garbage collection, and other performance problems. The tool provides comprehensive analysis of both JVM-specific metrics and system-level process information to help troubleshoot application issues.
